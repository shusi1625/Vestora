# Final Demo Scenario

## Goal

Show contracts, backend, frontend, and operations evidence working together.

## Draft Flow

1. Connect wallet on Sepolia.
2. Mint or use MockUSDC.
3. Create a receivable stream.
4. Show backend-indexed stream/listing data.
5. List the receivable NFT.
6. Show marketplace valuation data.
7. Buy the receivable NFT with another wallet.
8. Recheck owner and approval on-chain.
9. Claim available value.
10. Show API/indexer metrics and report tables.

## Evidence To Capture

- contract transaction hashes
- backend API response
- indexer lag metric
- marketplace UI state
- gas measurement table
- API latency table
- CloudWatch screenshot or exported metric table when AWS is introduced
