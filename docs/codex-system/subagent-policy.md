# Subagent Policy

Default: no subagent. Main agent reads, implements and verifies.

Delegate only when a bounded independent review or investigation benefits from separate context.
State the question, relevant paths, ownership and expected evidence before delegating.
Do not spawn a planner, explorer and verifier simply because a phase exists.
Do not give two writers the same files. Do not delegate sequential dependencies in parallel.
Keep returned evidence concise; main agent owns integration and final verification.

Existing .codex/agents files are optional role definitions, preserved for reuse.
The configured concurrency cap is not a target number of agents.
