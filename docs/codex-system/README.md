## What This System Optimizes

- lower repeated context usage
- narrower task routing
- role-based review without turning every task into multi-agent work
- phase-specific implementation flow
- evidence-backed reporting

## What This System Does Not Do

- add app-facing AI features
- replace the user's learning-led mode
- make backend projections settlement authority
- create cloud resources automatically
- make report claims without evidence
