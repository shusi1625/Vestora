# Metrics Plan

## Indexer Metrics

- latest chain block
- latest indexed block
- indexer lag
- processed logs per minute
- duplicate log skipped count
- RPC error rate
- backfill duration

## API Metrics

- request count
- p50 latency
- p95 latency
- p99 latency
- 4xx rate
- 5xx rate
- endpoint response time

## DB Metrics

- connection count
- query latency
- slow query count
- table row count
- index hit ratio

## Frontend/Product Metrics

- listing render time
- stream detail render time
- transaction confirmed to UI updated time
- RPC-only vs backend API listing load comparison

## Report Evidence

Use tables and screenshots where possible. Every performance claim should list:

- measurement date
- environment
- command or scenario
- sample size when available
- result
- limitation
